Phase 4 — Information-Guided Spectral Diffusion

▶

Goal

Improve noise schedule allocation using information-theoretic and per-band temporal dynamics — a fundamentally different approach from Phase 3’s noise amplitude/distribution experiments.

How Phase 4 differs from Phase 3: Phase 3 tried to refine what noise looks like (per-mode weights, shaped generation start). Phase 4 changes when the model trains and where DDIM steps are allocated. InfoNoise concentrates training on the empirical entropy-rate peak. Per-band schedules change temporal dynamics so different spectral bands are at different corruption stages at each timestep — but crucially, xT remains isotropic (no train/generate mismatch).

Sub-phases

PhaseApproachEffortRisk
4aInfoNoise adaptive timestep sampling (entropy-rate peak)1 weekMedium
4bInfoGrid DDIM (non-uniform reverse steps)3–5 daysLow
4cPer-band noise schedules (Esteves & Makadia)2–3 weeksHigh
4dSpectral conditioning of score network1 weekLow

Key Insight: Gradient Misallocation

The NS-D diagnostic (Phase 2f) showed 54% of gradient goes to mid-noise bins while the underfit low-noise regime (loss 0.72–1.10) gets only 14%. NS-A/NS-C couldn’t fix this. InfoNoise reframes the problem: maybe the GCN doesn’t need to learn at low noise — the “decision window” for community features is likely in the mid-noise range where the GCN is competent.

Motivated by

  • InfoNoise (Raya et al., arXiv:2602.18647) — information-guided noise allocation
  • Spectrally-Guided Schedules (Esteves & Makadia, arXiv:2603.19222) — per-instance noise schedules from spectral properties

Gate

W1 improvement > 0 on ≥1/2 families. Even if no W1 gain, the entropy-rate profile diagnostic for graph diffusion is a novel contribution.

Phase 5 — Frequency-Domain Diffusion

▶

Goal

Bypass the GCN bottleneck entirely by diffusing directly in the Laplacian eigenbasis — generating spectral coefficients c = UTx per eigenmode instead of node features x.

How Phase 5 differs from all prior phases: Phases 2–4 diffuse in the spatial domain (node features) and rely on a GCN to implicitly learn spectral structure. The GCN’s polynomial filter creates a capacity ceiling (loss 0.72–1.10 at low noise, confirmed in Phase 2f). Phase 5 pivots to the spectral domain: each eigenmode is a simple d-dimensional denoising problem solvable by an MLP — no graph convolution needed.

Sub-phases

PhaseApproachEffortRisk
5aIndependent per-mode diffusion (MLP per mode)1 weekMedium
5bAutoregressive spectral diffusion (low → high freq)2 weeksMedium
5cCross-mode attention diffusion (parallel + correlations)2–3 weeksHigh

Architecture

Project features to eigenbasis, run per-mode forward diffusion with mode-specific schedules (from Phase 4 theory), denoise with a shared MLP conditioned on (λk, t, Ek), then reconstruct via x = Uc.

Key Risk

Cross-mode correlations. Community features have correlated low/mid-frequency content. Independent per-mode generation (5a) may produce spectrally correct but spatially incoherent features. Variants 5b and 5c address this with autoregressive and attention-based cross-mode coupling.

Relationship to Phase 4

Phase 5 is independent of Phase 4 results. If Phase 4 shows large spatial-domain improvements, Phase 5 becomes less urgent. If Phase 4 plateaus, Phase 5 is the natural pivot. InfoNoise and per-mode schedules from Phase 4 apply directly in the spectral domain.
